## Key decisions to preserve

- **`Product` model is self-referential** — `children: list["Product"]`, mirrors Grocy's parent/child structure. `amount is None` signals a parent product; frontend renders a submenu. No `Variant` model.
- **Guest/host stripping** — single model, host-only fields (`host_notes`, `author`, `serving_notes`, `unmatched_ingredients`) default to `None`/`[]`. No separate guest models.
- **`method` is a `\n`-joined string** — frontend splits on `\n` to render numbered steps. The Notion API returns no markdown; steps are extracted from `numbered_list_item` blocks in page content.
- **Notion cache TTL is 12 hours** — `POST /api/crafted_drinks/refresh` for manual host-triggered refresh, returns `202 Accepted`, runs as a FastAPI `BackgroundTask`. On startup, if no cache row exists, populate before serving first request.
- **Equipment is a multi-select property** on the Notion drink page (not an embedded database) — saves one API call per drink (~81 calls for 40 drinks, ~27s at 3 req/s).
- **Notion API is slow** — throttle with `asyncio.Semaphore` at 3 req/s during cache refresh. Router always reads from SQLite; users never wait on Notion directly.
